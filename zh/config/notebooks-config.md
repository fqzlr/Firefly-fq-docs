# 笔记本配置详解

笔记本功能用于创建和管理多个独立的笔记本，支持日记、随笔、学习笔记等多种用途。

数据目录：`src/content/life/notebooks/`
Schema 定义：`src/content.config.ts` 中的 `notebooksCollection`

## 目录结构

每个笔记本是 `src/content/life/notebooks/` 下的一个子目录，包含：

- `_index.json` - 笔记本的元数据配置（名称、封面、简介等）
- 多个 `.md` 文件 - 笔记内容文件

```
src/content/life/notebooks/
├── 日记本/
│   ├── _index.json       # 笔记本配置
│   ├── 反思/
│   │   └── 反思.md       # 笔记文件
│   └── 对自己说的话/
│       └── 对自己说的话.md
├── 每日总结/
│   ├── _index.json
│   ├── 2026-06-11 每日总结.md
│   └── ...
├── 日常随笔/
│   ├── _index.json
│   └── ...
└── ...
```

支持的文件格式：
- `.md` - Markdown 格式的笔记文件
- `.json` - JSON 格式（主要用于 `_index.json` 配置文件）

## 笔记本配置（_index.json）

每个笔记本目录下必须有一个 `_index.json` 文件，用于定义笔记本的元信息。

### 字段说明

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `name` | `string` | 否 | `"未命名日记本"` | 笔记本名称 |
| `cover` | `string` | 否 | `""` | 封面图片 URL 或路径 |
| `summary` | `string` | 否 | `""` | 笔记本简介/描述 |
| `image` | `string \| string[]` | 否 | `""` | 图片（单张或多张） |
| `tags` | `string[]` | 否 | `[]` | 标签数组 |
| `date` | `date` | 否 | - | 创建日期 |

### 示例：_index.json

```json
{
  "name": "日记本",
  "summary": "记录自己的生活",
  "cover": "https://example.com/cover.jpg",
  "tags": ["日记", "生活"],
  "date": "2026-01-01"
}
```

## 笔记文件（.md）

每个笔记是一个独立的 `.md` 文件，使用 frontmatter 定义元数据，正文为笔记内容。

### 字段说明

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `name` | `string` | 否 | `"未命名日记本"` | 笔记标题 |
| `date` | `date` | 否 | - | 笔记日期 |
| `cover` | `string` | 否 | `""` | 封面图片 |
| `summary` | `string` | 否 | `""` | 摘要 |
| `image` | `string \| string[]` | 否 | `""` | 图片 |
| `tags` | `string[]` | 否 | `[]` | 标签数组 |

### 示例：笔记文件

```markdown
---
date: 2026-05-01
name: 反思
tags:
  - 反思
  - 成长
---

当我打王者上瘾的时候我就知道我又要废了。以后再自己玩王者、打巅峰赛我就是🐶
```

## 子目录支持

笔记本内可以创建子目录来组织笔记，支持任意层级的嵌套：

```
日记本/
├── _index.json
├── 反思/
│   └── 反思.md
├── 对自己说的话/
│   └── 对自己说的话.md
└── 2026年/
    ├── 1月/
    │   └── ...
    └── 2月/
        └── ...
```

子目录仅用于文件组织，不影响数据读取，系统会递归读取所有 `.md` 文件。

## 添加新笔记本

1. 在 `src/content/life/notebooks/` 下创建新目录，例如 `我的新笔记本`
2. 在新目录下创建 `_index.json` 文件，填写笔记本信息
3. 在目录下添加 `.md` 笔记文件

::: tip
- 每个笔记本目录下必须有 `_index.json` 才能被识别为笔记本
- 笔记文件使用 Markdown 格式，支持完整的 Markdown 语法
- 可以在笔记的 frontmatter 中设置 `date` 来指定日期
- 笔记本支持子目录嵌套，方便分类管理
:::
